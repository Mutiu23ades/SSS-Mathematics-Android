Lesson

Changing the subject of a formula means rearranging the formula so that a different variable is alone on one side.

Worked Examples

Example 1:
Make r the subject of A = πr².

Divide by π:
r² = A/π
Take the square root:
r = √(A/π)
Example 2:
Make t the subject of s = (u + v)t/2.

2s = (u + v)t
Therefore:
t = 2s/(u + v)

Practice Questions

1. Make x the subject of y = 3x + 5.
2. Make r the subject of C = 2πr.

Answers

1. x = (y − 5)/3
2. r = C/(2π)

Topic 25: Quadratic Formula

Lesson

For a quadratic equation:

ax² + bx + c = 0

the quadratic formula is:

x = [−b ± √(b² − 4ac)] / 2a

The expression b² − 4ac is called the discriminant.

Worked Examples

Example 1:
Solve x² − 5x + 6 = 0 using the formula.

a = 1, b = −5, c = 6

x = [5 ± √(25 − 24)]/2
x = [5 ± 1]/2
Therefore:
x = 3 or x = 2
Example 2:
Solve x² + 2x − 8 = 0.

a = 1, b = 2, c = −8
x = [−2 ± √(4 + 32)]/2
x = [−2 ± 6]/2
Therefore:
x = 2 or x = −4

Practice Questions

1. Solve x² − 3x − 4 = 0 using the quadratic formula.
2. Solve x² + 5x + 6 = 0.

Answers

1. x = 4 or −1
2. x = −2 or −3

Lesson

Completing the square changes a quadratic expression into the form:

(x + a)² + b

This method is useful for solving quadratic equations and finding the turning point of a parabola.

Complete the square for x² + 6x + 5.

Half of 6 is 3:

Example 2:

(x + 2)² − 9 = 0

x + 2 = ±3

Topic 27: Nature of Roots

Lesson

The nature of the roots of a quadratic equation is determined by its discriminant:

D = b² − 4ac

If D > 0, there are two distinct real roots.

If D = 0, there is one repeated real root.

If D < 0, there are no real roots.

Worked Examples

Example 1:
Determine the nature of the roots of x² − 5x + 6 = 0.

D = (−5)² − 4(1)(6)
= 25 − 24
= 1
Since D > 0, there are two distinct real roots.
Example 2:
Determine the nature of the roots of x² + 4x + 4 = 0.

D = 4² − 4(1)(4)
= 16 − 16
= 0
Therefore, there is one repeated real root.

Practice Questions

1. Find the nature of the roots of x² + 2x + 5 = 0.
2. Find the nature of the roots of x² − 6x + 9 = 0.

Answers

1. No real roots.
2. One repeated real root.

Topic 29: Arithmetic Progression

Lesson

An arithmetic progression (AP) is a sequence in which the difference between consecutive terms is constant.

The nth term is:

Tn = a + (n − 1)d

where a is the first term and d is the common difference.

Worked Examples

Example 1:
Find the 10th term of 3, 7, 11, 15, ...

a = 3, d = 4
T10 = 3 + 9(4)
= 39
Example 2:
Find the common difference of 12, 17, 22, 27, ...

17 − 12 = 5

Practice Questions

1. Find the 8th term of 2, 5, 8, 11, ...
2. Find the common difference of 20, 16, 12, 8, ...

Answers

1. 23
2. −4
