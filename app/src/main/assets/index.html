111. Indefinite Integration

Lesson

Indefinite integration is the process of finding the general antiderivative of a function.

It is called indefinite because there are no upper and lower limits.

The constant of integration C must be included because the derivative of any constant is zero.

The basic rule is:

∫xⁿ dx = xⁿ⁺¹/(n+1) + C

Worked Examples

Example 1: Integrate 6x².

∫6x² dx

= 6 × x³/3 + C

= 2x³ + C

Example 2: Integrate 4x³ - 6x + 5.

∫(4x³ - 6x + 5)dx

= x⁴ - 3x² + 5x + C

Answer = x⁴ - 3x² + 5x + C

Practice Questions

  1. Integrate 8x.
  2. Integrate 3x² + 4.
  3. Integrate 10x⁴ - 6x².

Answers

  1. 4x² + C
  2. x³ + 4x + C
  3. 2x⁵ - 2x³ + C

112. Definite Integration

Lesson

Definite integration is used when the integral has specified upper and lower limits.

It is written as:

∫ₐᵇ f(x) dx

To evaluate a definite integral:

  1. Find the antiderivative.
  2. Substitute the upper limit.
  3. Substitute the lower limit.
  4. Subtract the lower result from the upper result.

Worked Examples

Example 1: Evaluate ∫₀² x dx.

∫x dx = x²/2

Apply the limits:

[x²/2]₀²

= 2²/2 - 0²/2

= 4/2

= 2

Example 2: Evaluate ∫₁³ 2x dx.

∫2x dx = x²

[x²]₁³

= 3² - 1²

= 9 - 1

= 8

Practice Questions

  1. Evaluate ∫₀³ x dx.
  2. Evaluate ∫₁⁴ 2x dx.
  3. Evaluate ∫₀² 3x² dx.

Answers

  1. 9/2
  2. 15
  3. 8

113. Area Under a Curve

Lesson

Integration can be used to calculate the area between a curve and the x-axis over a specified interval.

The area between x = a and x = b is:

Area = ∫ₐᵇ y dx

When the curve lies above the x-axis, the definite integral gives the area directly.

Worked Examples

Example 1: Find the area under y = x from x = 0 to x = 2.

Area = ∫₀² x dx

= [x²/2]₀²

= 4/2 - 0

= 2 square units

Example 2: Find the area under y = x² from x = 0 to x = 2.

Area = ∫₀² x² dx

= [x³/3]₀²

= 8/3

= 2⅔ square units

Practice Questions

  1. Find the area under y = x from x = 0 to x = 4.
  2. Find the area under y = x² from x = 0 to x = 3.
  3. State the formula for the area under a curve.

Answers

  1. 8 square units
  2. 9 square units
  3. Area = ∫ₐᵇ y dx

114. Differential Equations

Lesson

A differential equation is an equation involving a function and one or more of its derivatives.

For example:

dy/dx = 2x

Solving a differential equation often involves integration.

Worked Examples

Example 1: Solve dy/dx = 3x².

Integrate both sides:

y = ∫3x² dx

y = x³ + C

Example 2: Solve dy/dx = 4x + 2.

Integrate:

y = ∫(4x + 2)dx

y = 2x² + 2x + C

Answer = 2x² + 2x + C

Practice Questions

  1. Solve dy/dx = 2x.
  2. Solve dy/dx = 6x².
  3. Solve dy/dx = 4x - 3.

Answers

  1. y = x² + C
  2. y = 2x³ + C
  3. y = 2x² - 3x + C

115. Numerical Methods

Lesson

Numerical methods are techniques used to obtain approximate numerical solutions to mathematical problems.

They are particularly useful when an exact algebraic solution is difficult or impossible to obtain.

Common numerical methods include:

  • Trial and improvement
  • Iteration
  • Newton-Raphson method
  • Bisection method

Worked Examples

Example 1: Use trial and improvement to approximate √10.

3² = 9

4² = 16

Therefore √10 lies between 3 and 4.

Try 3.16:

3.16² = 9.9856

Try 3.162:

3.162² ≈ 9.9982

Therefore:

√10 ≈ 3.162

Example 2: Use Newton-Raphson to find an approximation to a root of f(x) = x² - 2.

The Newton-Raphson formula is:

xₙ₊₁ = xₙ - f(xₙ)/f'(xₙ)

For f(x) = x² - 2:

f'(x) = 2x

Starting with x₀ = 1.5:

x₁ = 1.5 - (1.5² - 2)/(2 × 1.5)

x₁ ≈ 1.4167

A further iteration gives approximately:

x₂ ≈ 1.4142

Therefore √2 ≈ 1.4142.

Practice Questions

  1. What is a numerical method?
  2. Name two numerical methods.
  3. Use trial and improvement to estimate √5 to 3 decimal places.

Answers

  1. A technique for obtaining an approximate numerical solution.
  2. For example, iteration and Newton-Raphson method.
  3. √5 ≈ 2.236.
