Lesson

The main operations on sets are union, intersection and complement.

A ∪ B contains elements in A or B or both.

A ∩ B contains elements common to A and B.

A ∪ B = {1,2,3,4,5}

A ∩ B = {3}

Practice Questions

Lesson

A linear equation has the highest power of the variable equal to 1.

The aim is to isolate the unknown variable.

Example 2:

Topic 20: Linear Inequalities

Lesson

An inequality compares two quantities using symbols such as <, >, ≤ and ≥.

The important rule is that when an inequality is multiplied or divided by a negative number, the inequality sign must be reversed.

Worked Examples

Example 1:
Solve x + 4 > 9.

x > 9 − 4
Therefore, x > 5
Example 2:

Divide by −2 and reverse the sign:
x < −4

Practice Questions

2. Solve −3x ≥ 12.

Answers

2. x ≤ −4
