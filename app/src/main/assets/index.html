Topic 33: Partial Fractions

Lesson

Partial fractions involve expressing a rational algebraic expression as a sum of simpler fractions.

Worked Examples

Example 1:
Express 5/[(x+1)(x+2)] as partial fractions.

Let:
5/[(x+1)(x+2)] = A/(x+1) + B/(x+2)

5 = A(x+2) + B(x+1)
Putting x = −1 gives A = 5.
Putting x = −2 gives B = −5.

Therefore:
5/(x+1) − 5/(x+2)
Example 2:
Express 3/[(x−1)(x+1)] as partial fractions.

Let:
3/[(x−1)(x+1)] = A/(x−1) + B/(x+1)

Putting x = 1 gives A = 3/2.
Putting x = −1 gives B = −3/2.

Answer:
3/[2(x−1)] − 3/[2(x+1)]

Practice Questions

Topic 40: Inverse of a Matrix

Lesson

The inverse of a matrix A is written as A−1.

For:

A = [a b; c d]

the inverse is:

A−1 = 1/(ad−bc) [d −b; −c a]

The determinant must not be zero.

Worked Examples

Example 1:
Find the inverse of [2 1; 1 1].

Determinant = 2(1) − 1(1) = 1.

Therefore:
A−1 = [1 −1; −1 2]
Example 2:
For A = [3 1; 2 1], find the determinant first.

|A| = 3(1) − 1(2)
= 1
Since the determinant is non-zero, the matrix has an inverse.

Practice Questions

1. Find the determinant of [4 1; 2 3].
2. Does [2 4; 1 2] have an inverse?

Answers

1. 10
2. No. Its determinant is 2(2)−4(1)=0.
