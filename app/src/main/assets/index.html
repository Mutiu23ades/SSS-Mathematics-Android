91. Standard Deviation

Lesson

Standard deviation is a measure of how widely data values are spread around the mean.

It is the positive square root of the variance.

Standard deviation = √Variance

A small standard deviation means the values are close to the mean. A large standard deviation means the values are more widely spread.

Worked Examples

Example 1: Find the standard deviation of 2, 4 and 6.

Mean = (2 + 4 + 6)/3 = 4

Squared deviations = 4, 0, 4

Variance = 8/3

Standard deviation = √(8/3)

≈ 1.63

Example 2: If the variance of a data set is 25, find its standard deviation.

Standard deviation = √25

= 5

Practice Questions

  1. If variance is 36, find the standard deviation.
  2. If variance is 49, find the standard deviation.
  3. What does a small standard deviation indicate?

Answers

  1. 6
  2. 7
  3. The values are closely grouped around the mean.

92. Probability

Lesson

Probability measures how likely an event is to occur.

The probability of an event E is:

P(E) = Number of favourable outcomes / Total number of possible outcomes

Probability lies between 0 and 1.

  • P(E) = 0 means impossible.
  • P(E) = 1 means certain.
  • Values between 0 and 1 represent different levels of likelihood.

The complement of an event is:

P(E') = 1 - P(E)

Worked Examples

Example 1: A fair die is thrown. Find the probability of obtaining a 4.

Favourable outcomes = 1

Total outcomes = 6

P(4) = 1/6

Answer = 1/6

Example 2: A bag contains 3 red balls and 7 blue balls. Find the probability of selecting a red ball.

Total balls = 10

Red balls = 3

P(red) = 3/10

= 0.3

Practice Questions

  1. Find the probability of obtaining a head when a fair coin is tossed.
  2. A die is thrown. Find P(6).
  3. If P(A) = 0.4, find P(A').

Answers

  1. 1/2
  2. 1/6
  3. 0.6

Experimental probability is based on the results obtained from an actual experiment or observation.

A permutation is an arrangement of objects where the order is important.

Factorial notation is written as n!.

97. Probability of Combined Events

Lesson

Combined events involve two or more events.

For mutually exclusive events:

P(A or B) = P(A) + P(B)

For independent events:

P(A and B) = P(A) × P(B)

Two events are independent when the occurrence of one does not affect the probability of the other.

Worked Examples

Example 1: A die is thrown. Find the probability of obtaining 1 or 6.

P(1) = 1/6

P(6) = 1/6

P(1 or 6) = 1/6 + 1/6

= 1/3

Example 2: A coin is tossed twice. Find the probability of obtaining two heads.

P(head on first toss) = 1/2

P(head on second toss) = 1/2

P(two heads) = 1/2 × 1/2

= 1/4

Practice Questions

  1. A die is thrown. Find P(2 or 5).
  2. A coin is tossed twice. Find P(two tails).
  3. A coin is tossed twice. Find P(head then tail).

Answers

  1. 1/3
  2. 1/4
  3. 1/4

100. Domain and Range

Lesson

The domain of a function is the set of allowed input values.

The range is the set of possible output values.

For example, if f(x) = x + 2 and the domain is {1,2,3}, then the range is {3,4,5}.

Worked Examples

Example 1: Given f(x) = x + 3 and domain {0,1,2}, find the range.

f(0) = 3

f(1) = 4

f(2) = 5

Range = {3,4,5}

Example 2: Find the domain restriction for f(x) = 1/(x-2).

The denominator cannot be zero.

x - 2 ≠ 0

x ≠ 2

Therefore the domain is all real numbers except 2.

Practice Questions

  1. For f(x) = x + 1 with domain {1,2,3}, find the range.
  2. For f(x) = 2x with domain {0,1,2}, find the range.
  3. State the restriction on x for f(x) = 1/(x-5).

Answers

  1. {2,3,4}
  2. {0,2,4}
  3. x ≠ 5
