Topic 41: Identity Matrix

Lesson

An identity matrix is a square matrix with 1s on the main diagonal and 0s everywhere else.

The 2 × 2 identity matrix is:

I = [1 0; 0 1]

For a suitable matrix A:

AI = IA = A

Worked Examples

Example 1:
Write the 3 × 3 identity matrix.

[1 0 0; 0 1 0; 0 0 1]
Example 2:
If A = [2 3; 4 5], find AI.

Using the identity matrix does not change A.
Therefore:
AI = [2 3; 4 5]

Practice Questions

1. Write the 2 × 2 identity matrix.
2. If A = [7 2; 1 5], find AI.

Answers

1. [1 0; 0 1]
2. [7 2; 1 5]

Lesson

Reflection produces a mirror image of a shape in a given mirror line.

Useful rules include:

Reflection in the x-axis: (x,y) → (x,−y)

(2,5)

Topic 45: Rotation

Lesson

Rotation turns a shape about a fixed point called the centre of rotation.

About the origin:

90° anticlockwise: (x,y) → (−y,x)

90° clockwise: (x,y) → (y,−x)

180°: (x,y) → (−x,−y)

Worked Examples

Example 1:
Rotate (2,3) through 90° anticlockwise about the origin.

(2,3) → (−3,2)
Example 2:
Rotate (4,1) through 180° about the origin.

(4,1) → (−4,−1)

Practice Questions

1. Rotate (3,2) through 90° anticlockwise about the origin.
2. Rotate (5,−1) through 180° about the origin.

Answers

1. (−2,3)
2. (−5,1)

Lesson

Plane geometry deals with flat two-dimensional shapes such as triangles, quadrilaterals, circles and polygons.

Important ideas include points, lines, angles, shapes, symmetry and measurements.

Worked Examples

Example 1:
Find the angle on a straight line if one angle is 65°.

Angles on a straight line add to 180°.
Angle = 180° − 65°
= 115°

The angles of a triangle are 50° and 60°. Find the third angle.

Third angle = 180° − 50° − 60°
= 70°

Topic 49: Angles and Lines

Lesson

Angles are formed when two lines meet.

Angles on a straight line add to 180°.

Angles around a point add to 360°.

Vertically opposite angles are equal.

Worked Examples

Example 1:
Two angles on a straight line are x and 75°. Find x.

x + 75° = 180°
x = 105°
Example 2:
Angles around a point are 90°, 80°, 70° and x.

90 + 80 + 70 + x = 360
240 + x = 360
x = 120°

Practice Questions

1. Find x if x + 65° = 180°.
2. Find x if angles around a point are 100°, 80°, 90° and x.

Answers

1. 115°
2. 90°

Topic 50: Triangles

Lesson

A triangle is a polygon with three sides and three angles.

The sum of the interior angles of a triangle is always 180°.

Types include equilateral, isosceles and scalene triangles.

Worked Examples

Example 1:
Find the third angle of a triangle whose angles are 55° and 65°.

Third angle = 180° − 55° − 65°

Third angle = 180° − 40° − 40°
= 100°

Practice Questions

2. An equilateral triangle has what size for each interior angle?
