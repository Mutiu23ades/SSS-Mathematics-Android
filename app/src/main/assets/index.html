Topic 1: Number Bases

Lesson

A number base tells us how many different digits are used in a number system.

In base 10, the digits are 0–9. In base 2, the digits are 0 and 1.

The value of each digit depends on its position.

For example:

10112 = 1(2³) + 0(2²) + 1(2¹) + 1(2⁰)

= 8 + 0 + 2 + 1 = 1110

Worked Examples

Example 1:
Convert 101012 to base 10.

101012 = 1(16) + 0(8) + 1(4) + 0(2) + 1(1)
= 16 + 4 + 1
= 2110
Example 2:
Convert 2510 to base 2.

25 ÷ 2 = 12 remainder 1
12 ÷ 2 = 6 remainder 0
6 ÷ 2 = 3 remainder 0
3 ÷ 2 = 1 remainder 1
1 ÷ 2 = 0 remainder 1

Reading the remainders upwards:
110012

Practice Questions

1. Convert 110102 to base 10.
2. Convert 1810 to base 2.

Answers

1. 2610
2. 100102

Topic 2: Fractions

Lesson

A fraction represents part of a whole. It has a numerator and denominator.

For example, in 3/5, 3 is the numerator and 5 is the denominator.

Fractions may be proper, improper or mixed numbers.

Worked Examples

Example 1:
Calculate 1/3 + 1/6.

LCM of 3 and 6 = 6
1/3 = 2/6
Therefore:
2/6 + 1/6 = 3/6 = 1/2
Example 2:
Calculate 3/4 ÷ 2/5.

Change division to multiplication by the reciprocal:
3/4 × 5/2 = 15/8
= 1 7/8

Practice Questions

2. Calculate 3/7 × 14/9.

Answers

1. 1/2
2. 2/3

Topic 4: Approximation

Lesson

Approximation means replacing a number with a nearby value that is easier to use.

Numbers may be rounded to decimal places or significant figures.

Worked Examples

Example 1:
Round 7.846 to 2 decimal places.

The third decimal digit is 6, so increase the second decimal digit.
Answer: 7.85
Example 2:
Round 5,763 to 2 significant figures.

The first two significant figures are 5 and 7.
The next digit is 6, so 57 becomes 58.
Answer: 5,800

Practice Questions

2. Round 8,456 to 2 significant figures.

Answers

1. 12.68

Lesson

Estimation involves finding an approximate answer by using rounded values.

It is useful for checking whether an exact answer is reasonable.

Worked Examples

Example 1:
Estimate 49 × 21.

49 ≈ 50
21 ≈ 20
50 × 20 = 1,000
Example 2:
Estimate 398 ÷ 19.

398 ≈ 400
19 ≈ 20
400 ÷ 20 = 20

Practice Questions

2. Estimate 597 ÷ 21.

Answers

1. About 1,800
2. About 30

Topic 7: Logarithms

Lesson

A logarithm is another way of expressing an index.

If ax = N, then:

logaN = x

Worked Examples

Example 1:
Evaluate log2 8.

Since 2³ = 8,

Example 2:

Therefore, x = 1000.

Practice Questions

Topic 8: Laws of Logarithms

Lesson

The main laws are:

log(ab) = log a + log b

log(a/b) = log a − log b

log(an) = n log a

Worked Examples

Example 1:
Simplify log 5 + log 2.

Using the product law:
log(5 × 2) = log 10 = 1
Example 2:
Simplify 3 log x.

Using the power law:
3 log x = log(x³)

Practice Questions

1. Simplify log 4 + log 25.
2. Write 2 log x as one logarithm.

Answers

1. log 100 = 2
2. log(x²)

Topic 9: Indices

Lesson

An index shows how many times a number is multiplied by itself.

For example, 2³ = 2 × 2 × 2 = 8.

Important laws include:

am × an = am+n

am ÷ an = am-n

(am)n = amn

Worked Examples

Example 1:
Simplify 2³ × 2⁴.

2³ × 2⁴ = 23+4
= 2⁷ = 128
Example 2:
Solve 2x = 32.

32 = 2⁵
Therefore:
x = 5

Practice Questions

1. Simplify 3² × 3³.
2. Solve 5x = 125.

Answers

1. 3⁵ = 243
2. x = 3

Topic 10: Laws of Indices

Lesson

The laws of indices help us simplify expressions involving powers.

For multiplication with the same base, add the powers.

For division with the same base, subtract the powers.

For a power raised to another power, multiply the powers.

Worked Examples

Example 2:
