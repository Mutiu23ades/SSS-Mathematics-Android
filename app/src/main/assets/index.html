101. Composite Functions

Lesson

A composite function is formed when one function is applied to another function.

It is written as:

(fg)(x) = f(g(x))

This means that g(x) is found first, then the result is substituted into f.

Worked Examples

Example 1: If f(x) = 2x + 1 and g(x) = x + 3, find f(g(x)).

f(g(x)) = 2(x + 3) + 1

= 2x + 6 + 1

= 2x + 7

Example 2: If f(x) = x² and g(x) = x + 2, find f(g(3)).

g(3) = 3 + 2 = 5

f(5) = 5² = 25

Answer = 25

Practice Questions

  1. If f(x) = 3x + 2 and g(x) = x + 1, find f(g(x)).
  2. If f(x) = x² and g(x) = x - 2, find f(g(5)).
  3. If f(x) = 2x and g(x) = x + 4, find f(g(3)).

Answers

  1. 3x + 5
  2. 9
  3. 14

102. Inverse Functions

Lesson

The inverse of a function reverses the operation of the original function.

The inverse of f(x) is written as f⁻¹(x).

To find an inverse:

  1. Write y = f(x).
  2. Interchange x and y.
  3. Make y the subject.
  4. Replace y with f⁻¹(x).

Worked Examples

Example 1: Find the inverse of f(x) = 2x + 3.

y = 2x + 3

Interchange x and y:

x = 2y + 3

x - 3 = 2y

y = (x - 3)/2

f⁻¹(x) = (x - 3)/2

Example 2: Find the inverse of f(x) = 5x - 1.

y = 5x - 1

x = 5y - 1

x + 1 = 5y

f⁻¹(x) = (x + 1)/5

Practice Questions

  1. Find the inverse of f(x) = 3x + 2.
  2. Find the inverse of f(x) = 4x - 5.
  3. Find the inverse of f(x) = x + 7.

Answers

  1. f⁻¹(x) = (x - 2)/3
  2. f⁻¹(x) = (x + 5)/4
  3. f⁻¹(x) = x - 7

103. Limits

Lesson

A limit describes the value that a function approaches as the input approaches a particular value.

It is written as:

lim f(x) as x → a

Limits are important in calculus because they provide the foundation for differentiation and continuity.

Worked Examples

Example 1: Find lim(x + 3) as x → 2.

Substitute x = 2:

2 + 3 = 5

Example 2: Find lim(x² + 1) as x → 3.

= 3² + 1

= 9 + 1

= 10

Practice Questions

  1. Find lim(x + 5) as x → 4.
  2. Find lim(2x + 1) as x → 3.
  3. Find lim(x²) as x → 5.

Answers

  1. 9
  2. 7
  3. 25

104. Differentiation

Lesson

Differentiation is the process of finding the derivative of a function.

The derivative represents the rate of change of one quantity with respect to another. For a curve, it can represent the gradient at a particular point.

For a power of x:

d/dx(xⁿ) = nxⁿ⁻¹

Worked Examples

Example 1: Differentiate y = x³.

dy/dx = 3x²

Answer = 3x²

Example 2: Differentiate y = 5x² + 3x - 7.

dy/dx = 10x + 3

Answer = 10x + 3

Practice Questions

  1. Differentiate y = x⁴.
  2. Differentiate y = 3x² + 2x + 1.
  3. Differentiate y = 7x³ - 4x.

Answers

  1. 4x³
  2. 6x + 2
  3. 21x² - 4

105. Differentiation from First Principles

Lesson

Differentiation from first principles uses the limit definition of the derivative.

The formula is:

f'(x) = lim[h → 0] {f(x+h) - f(x)}/h

This method provides the fundamental definition of differentiation.

Worked Examples

Example 1: Differentiate f(x) = x² from first principles.

f(x+h) = (x+h)²

= x² + 2xh + h²

Therefore:

[f(x+h)-f(x)]/h

= [x² + 2xh + h² - x²]/h

= [2xh + h²]/h

= 2x + h

As h → 0:

f'(x) = 2x

Example 2: Differentiate f(x) = x³ from first principles.

f(x+h) = (x+h)³

= x³ + 3x²h + 3xh² + h³

Subtract x³ and divide by h:

= 3x² + 3xh + h²

As h → 0:

f'(x) = 3x²

Practice Questions

  1. Differentiate f(x) = x² from first principles.
  2. Differentiate f(x) = x³ from first principles.
  3. State the first-principles formula.

Answers

  1. 2x
  2. 3x²
  3. f'(x) = lim[h→0] [f(x+h)-f(x)]/h

106. Rules of Differentiation

Lesson

Several rules make differentiation of algebraic functions easier.

Power Rule: d/dx(xⁿ) = nxⁿ⁻¹

Constant Rule: The derivative of a constant is zero.

Constant Multiple Rule: A constant multiplied by a function remains as a multiplier after differentiation.

Sum Rule: Differentiate each term separately.

Worked Examples

Example 1: Differentiate y = 6x⁴.

dy/dx = 6(4x³)

= 24x³

Example 2: Differentiate y = 4x³ - 5x² + 2x - 8.

dy/dx = 12x² - 10x + 2

Answer = 12x² - 10x + 2

Practice Questions

  1. Differentiate y = 8x³.
  2. Differentiate y = 5x⁴ - 2x² + 7.
  3. Differentiate y = 9x² - 4x + 6.

Answers

  1. 24x²
  2. 20x³ - 4x
  3. 18x - 4

107. Applications of Differentiation

Lesson

Differentiation has many applications. It can be used to find gradients, rates of change, stationary points and maximum or minimum values.

For a curve y = f(x), the gradient is:

dy/dx

At a stationary point:

dy/dx = 0

Worked Examples

Example 1: Find the gradient of y = x² + 3x at x = 2.

dy/dx = 2x + 3

At x = 2:

= 2(2) + 3

= 7

Example 2: Find the stationary point of y = x² - 4x + 3.

dy/dx = 2x - 4

At a stationary point:

2x - 4 = 0

x = 2

Substitute x = 2:

y = 2² - 4(2) + 3

= 4 - 8 + 3

y = -1

Stationary point = (2,-1)

Practice Questions

  1. Find the gradient of y = x² + 2x at x = 3.
  2. Find the stationary point of y = x² - 6x + 5.
  3. What equation is used to find stationary points?

Answers

  1. 8
  2. (3,-4)
  3. dy/dx = 0

108. Maximum and Minimum Values

Lesson

Differentiation can be used to determine whether a stationary point is a maximum or minimum.

First find the stationary point using:

dy/dx = 0

Then use the second derivative.

  • If d²y/dx² > 0, the point is a minimum.
  • If d²y/dx² < 0, the point is a maximum.

Worked Examples

Example 1: Determine the nature of the stationary point of y = x² - 4x + 1.

dy/dx = 2x - 4

2x - 4 = 0

x = 2

Second derivative:

d²y/dx² = 2

Since 2 > 0, the stationary point is a minimum.

Example 2: Determine the nature of the stationary point of y = -x² + 6x.

dy/dx = -2x + 6

-2x + 6 = 0

x = 3

d²y/dx² = -2

Since -2 < 0, the stationary point is a maximum.

Practice Questions

  1. If the second derivative is positive at a stationary point, what type of point is it?
  2. If the second derivative is negative, what type of point is it?
  3. Determine the nature of the stationary point of y = x² - 2x.

Answers

  1. Minimum.
  2. Maximum.
  3. Minimum.

109. Rates of Change

Lesson

The derivative measures the rate at which one quantity changes with respect to another.

If distance s is a function of time t, then:

Velocity = ds/dt

The second derivative gives acceleration:

Acceleration = d²s/dt²

Worked Examples

Example 1: The distance travelled by a particle is s = t² + 3t. Find its velocity at t = 4.

Velocity = ds/dt

= 2t + 3

At t = 4:

= 2(4) + 3

= 11 units per second

Example 2: If s = 2t³, find the velocity.

v = ds/dt

= 6t²

Practice Questions

  1. If s = t² + 5t, find the velocity.
  2. If s = 3t², find the velocity at t = 2.
  3. If velocity v = 6t, find acceleration.

Answers

  1. v = 2t + 5
  2. 12 units per second
  3. 6 units per second squared

110. Integration

Lesson

Integration is the reverse process of differentiation.

It is used to find accumulated quantities and areas under curves.

The basic power rule for integration is:

∫xⁿ dx = xⁿ⁺¹/(n+1) + C

where C is the constant of integration.

Worked Examples

Example 1: Integrate 3x².

∫3x² dx

= 3(x³/3) + C

= x³ + C

Example 2: Integrate 4x³ + 2x.

∫(4x³ + 2x)dx

= x⁴ + x² + C

Answer = x⁴ + x² + C

Practice Questions

  1. Integrate 2x.
  2. Integrate 5x².
  3. Integrate 6x³ + 4x.

Answers

  1. x² + C
  2. (5/3)x³ + C
  3. (3/2)x⁴ + 2x² + C
